# Gallery 

### A simple Android image viewer.


### ADB

#### Install/Uninstall Apps
```
adb uninstall com.robertotorino.gallery
adb install app\build\outputs\apk\debug\gallery-debug.apk
adb shell pm clear com.robertotorino.gallery
```
